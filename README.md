# 🤖 Gemini AI Chatbot

## Project Overview
An interactive AI chatbot built using Python, Streamlit and Google's Gemini Generative AI model.

## Features
- AI-generated responses using Gemini
- Conversation history and memory
- Custom AI instructions
- Clear chat functionality
- Adjustable response creativity
- Chat statistics
- Professional Streamlit interface
- Error handling

## Technologies Used
- Python
- Google Gemini API
- Streamlit
- Google GenAI SDK
- Python-dotenv

## Installation

1. Clone the repository.
2. Create a virtual environment.
3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Create a `.env` file and configure your Gemini API key:

```env
GEMINI_API_KEY=your_actual_api_key
```

5. Run the application:

```bash
streamlit run app.py
```
